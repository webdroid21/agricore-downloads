# AgriCore — App Downloads

Public downloads for the AgriCore mobile app. Source code is private; this repo only ships installable releases.

## Android

**[Download the latest APK](https://github.com/webdroid21/agricore-downloads/releases/latest/download/agricore.apk)**

1. Open the link on your Android phone (or download and transfer the `.apk` file).
2. Tap the downloaded file → **Install**. Android may ask to allow installs from your browser/files app — approve it.
3. Open **AgriCore** and sign in with your usual credentials.
